# TypeRacer 3D

A beginner-friendly browser typing-race game. Correct words advance your car; typing speed updates WPM and speedometer. Race against three AI-style opponents.

## Run in VS Code
1. Extract this ZIP.
2. Open the `typeracer-3d` folder in VS Code.
3. Open `index.html`.
4. Either double-click `index.html` to open it in a browser, or install the **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.
5. Press **Start Race**, type the highlighted word, then press **Space** or **Enter**.
6. Press **↻ Restart** to play again.

## Features
- Responsive layout for PC/laptop and mobile browsers
- Typing speed (WPM), accuracy, elapsed timer, speedometer
- Perspective neon track, finish line, player car and three AI opponents
- Race result screen and restart button
- No npm install, no external libraries, no internet required after download

Note: the track uses a custom canvas drawing with a 3D-style perspective. It is not a full WebGL physics simulator.
